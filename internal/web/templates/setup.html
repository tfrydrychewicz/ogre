Type go links in your browser

This Directory answers go links at {{.DirectoryURL}}.

To type go/name in Chrome's address bar, load the Ogre extension: it sends every go link to this Directory. Without it, a search shortcut does nearly the same (last section). Any go link also opens at {{.DirectoryURL}}/name, in any browser.

1. Load the extension

  1. Open a new tab and type chrome://extensions {{template "setup-copy" "chrome://extensions"}} in the address bar. Chrome doesn't let pages link there, so type or paste it.
  2. Turn on Developer mode, the switch in the top right corner.
  3. Click Load unpacked.
    4. {{if .ExtensionDir}}
  4. Choose this folder: {{.ExtensionDir}} {{template "setup-copy" .ExtensionDir}}
    5. {{else}}
  5. Choose the folder named extension at the top of your copy of the Ogre repository.
    6. {{end}}
  6. Ogre now appears among your extensions. Leave it switched on.

2. Check that it works

  1. Type go/ in the address bar, with the slash, and press Enter. This Directory's home page opens.
  2. Type a go link you have created, such as go/name, and press Enter. You land where the link points. No links yet? Create one.

3. If Chrome searches instead of opening the link

Until Chrome knows go as a site, it may treat go/name as words to search for.

  1. Type go/, with the slash, and press Enter. Once is enough: after that, go/name opens the link.
  2. Until then, end the link with a slash, go/name/, or type it in full, http://go/name. Chrome always opens those as addresses.

4. Incognito windows

Chrome doesn't run extensions in Incognito windows unless you allow it. Without it, a go link typed in an Incognito window ends on Chrome's error page.

  1. Open chrome://extensions.
  2. Click Details under Ogre.
  3. Turn on Allow in Incognito.
Not tested yet

Whether go links work in Incognito once the extension is allowed there has not been tried.

5. Without the extension: a search shortcut

A search shortcut sends what you type after a keyword to this Directory. You type go, a space or tab, then the link without go/.

  1. Open chrome://settings/searchEngines {{template "setup-copy" "chrome://settings/searchEngines"}}
  2. Next to Site search, click Add.
  3. Fill in:
    Name
    Ogre
    Shortcut
    go
    URL with %s in place of query
    {{.ShortcutURL}} {{template "setup-copy" .ShortcutURL}}
  4. Click Add.
  5. In the address bar, type go, press Tab (or Space), type the link, such as roadmap, and press Enter.

If you often search for words that start with “go”, choose another shortcut, such as og. Other browsers have the same feature under names like “keyword” or “custom search engine”.
