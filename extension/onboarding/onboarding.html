go/Ogre Settings

Set up go links

Three short steps make go/name work in this browser. This page notices the first two by itself.

  1. 1. Your Ogre server

    Checking

    The extension sends go links to ….

    Start it in a terminal, then come back to this page:

    • In your copy of the Ogre repository: go run ./cmd/ogre (or make run)
    • Or, with the program already built (make build puts it in bin/): bin/ogre

    Leave the terminal open: the server runs until you stop it with Ctrl+C. This page checks again when you come back to it.

    Something answers at this address, but not as an Ogre server this extension can use. When another program holds the port, Ogre cannot start there either. Start Ogre on a free port instead, for example:

    • go run ./cmd/ogre --addr localhost:4656

    Then open Settings and save the address it prints, such as http://localhost:4656. This page follows the new address by itself.

    Server somewhere else? Change the address

  2. 2. Type go/ once

    Waiting for step 1

    This step starts once your server answers. Until then, Chrome would not remember the visit.

    1. Open a new tab (Ctrl+T).
    2. Type go/, with the slash, and press Enter.

    Your server's home page opens in that tab. Chrome now knows go as a site, so from now on it opens go links instead of searching for them.

  3. 3. Try a go link

    Waiting for step 2

    This step starts once step 2 is done.

    Type a go link without a slash at the end, such as go/roadmap, and press Enter. Chrome opens it on your server: its page, or "Did you mean", or an offer to create it.

    If Chrome searches for it instead, it hasn't learned go as a site yet. Type go/ and press Enter once more. Until that works, end the link with a slash, go/roadmap/, or type it in full, http://go/roadmap: Chrome always opens those as addresses.
