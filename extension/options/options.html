go/Ogre Extension settings

Settings

The extension sends every go link you open to your Ogre server, the Directory.

Directory

Go links now go to ….

The address of your Ogre server: http:// or https://, its name, and a port if it has one; nothing after that. A server started on this computer with its default settings is at http://localhost:4655.
Warning: no Ogre server answers there

You can save the address anyway, for a server you will start later. Until it runs, go links end on Chrome's error page.

What the extension may reach

The extension acts on go links and talks to one server, the Directory above. It reads no other site and sends nothing anywhere else.

A server at another address than the default needs your permission: when you test or save such an address, Chrome asks whether the extension may contact that one server. When you save, access to any other server you allowed before is given up. Access you allowed only to test an address you did not save is given up the next time Chrome starts.

First-run check

The first-run page checks that your server answers and teaches Chrome to open go/name as an address instead of searching for it.
